# Posvyat Bot 2026–2027

Telegram-бот для регистрации участников посвящения. Пользователь заполняет анкету, проверяет введённые данные и переходит к этапу оплаты.

> Проект находится в активной разработке.

## Что уже реализовано

- команды `/start` и `/help`;
- главное меню с кнопкой покупки билета;
- пошаговая анкета на FSM: ФИО, дата рождения и группа/вуз;
- проверка формата и корректности даты рождения;
- ограничение по возрасту 18+;
- экран проверки введённых данных;
- возможность подтвердить, заполнить заново или отменить анкету;
- переход к экрану с реквизитами и кнопкой «Оплатил»;
- отправка заявки администратору;
- подтверждение или отклонение оплаты;
- хранение заявок в SQLite;
- один активный билет на Telegram-пользователя;
- выгрузка подтверждённых покупателей в Excel по команде `/buyers`.

## Сценарий пользователя

```text
/start
  └─ Купить билет
      └─ ФИО
          └─ Дата рождения
              └─ Группа или вуз
                  └─ Проверка данных
                      ├─ Подтвердить → оплата → проверка администратором
                      ├─ Изменить → повторное заполнение
                      └─ Отменить → главное меню
```

## Настройка

Создайте локальный файл конфигурации из примера:

```bash
cp .env.example .env
```

На Windows вместо этого можно выполнить:

```powershell
Copy-Item .env.example .env
```

Заполните `.env`:

```dotenv
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=123456789
ADMIN_CONTACT=@admin_username
LOG_LEVEL=INFO
LOG_FORMAT="[%(asctime)s] #%(levelname)-8s %(filename)s:%(lineno)d - %(name)s - %(message)s"
```

`BOT_TOKEN` — токен Telegram-бота, полученный у BotFather. `ADMIN_IDS` — числовые Telegram ID администраторов через запятую. `ADMIN_CONTACT` — контакт для вопросов по отклонённой заявке. Файл `.env` содержит секреты и не должен попадать в Git.

## Запуск

```bash
python main.py
```

## Структура проекта

```text
posvyat_bot_2026_2027/
├── config/       # загрузка настроек из окружения
├── database/     # SQLite и операции с заявками
├── handlers/     # команды, анкета и FSM-обработчики
├── keyboards/    # reply- и inline-клавиатуры
├── lexicon/      # пользовательские тексты
├── services/     # формирование Excel-файла
├── .env.example  # пример переменных окружения
└── main.py       # точка входа
```

## Важно перед реальным запуском

Бот собирает ФИО и дату рождения — это персональные данные. Перед использованием на реальном мероприятии необходимо определить срок хранения данных, ограничить доступ администраторов, предусмотреть удаление заявок и не выводить чувствительные данные в логи.
